## Story

It is a terminal game made using curses library in python. It has a game screen on right to display character and story text is displayed on left. The story is that you are invited to a halloween party by your friends. Sadly you are broke as always , you dont haven money to buy a creepy halloween custome.But it is not a normal halloween for you as you have just discovered your super nature ability to see ghostly world. There are specific spiritural points in your realm where the wall between two realm is weak. You have to use that point to enter ghostly realm. Use ghostly vision to see spiritual points .You have to do missions by catching spirits and earn coins so you can buy yourself a halloween costume.  

## Game

It starts with horror blink effect and witch laughter , then with creepy background sound the game screen appears on right and story on left , press enter to go through the story . You can control player movement with WASD keys and press "m" for ghost vision and see spiritual points . Point "s" refers to ghostly shop and point "m" refers to missions . For missions you have to catch apirits that are running away from you as you are a famous spirit catcher, each mission will give you 100 coins . Mission has a different sound track and shop has costumes with different prizes.

## how to play

### option 1 - download the release

Download the game from the GitHub release: 
https://github.com/Atharv-Shukla-987/catch_the_spirit/releases/tag/catch_the_spirit

Extract the zip file and run the exe file and enjoy your hunt for halloween costume.

### option 2 - run from source

Clone the repository:
```
git clone https://github.com/Atharv-Shukla-987/catch_the_spirit.git
```
Enter the project directory:
```
cd catch_the_spirit
```
Install the required Python package:
```
pip install playsound3
```
Run the game:
```
python main.py
```
